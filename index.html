How to Play

Weapons fire on their own — your job is to position. Stay alive through each floor's horde until its gate Warden drops, then bring the Warden down to descend. Do it ten times.

The run loop

01 · Survive

Ride the horde

Machines pour in and thicken over time. Your guns auto-target; you kite, thin the pack, and scoop the XP shards they drop.

02 · Level

Take an augment

Fill the XP bar to level up and pick one of three — a new weapon, a passive, or a floor-tagged skill. The offer only appears when you reach the next level.

03 · Fuse

Evolve the build

Level two matching weapons and the panel offers a fusion — one stronger weapon in place of the pair. Four slots, so every pick is a commitment.

04 · The gate

Kill the Warden

When the floor's hold expires the gate slams down and a Warden lands. It breaks through phases and never dies quietly — put it down and the floor is cleared.

05 · Descend

Go deeper

Each floor is a wholly different place — new ground, an exclusive roster of machines, a new Warden. Ten floors to the Centre of the Earth.

Between runs

Spend the web

Tokens buy nodes on the skill web; salvaged relics bolt onto your frame. This is how a frame grows run-over-run — and how you get strong enough for HELL.

The difficulty ladder

EASYThe default. Enemies deal 0.6× damage and carry 0.75× health — room to learn the floors and the frames with the pressure turned down.
NORMALThe baseline the whole game is tuned around — 1.0× across the board, no floor mechanics.
HARDEnemies deal 1.25× damage, carry 1.35× health, spawn denser, and lunge the moment you get close. Still no floor mechanics.
HELLEnemies deal 1.6× damage, carry 1.7× health, spawn denser still, and fire a parting shot as they die — and every one of the ten floors runs its own live mechanic. Unlocked by buying BLACK ICE CLEARANCE on the skill web. Full breakdown in the HELL section.

The Skill Web

Between runs you spend earned tokens here for permanent upgrades. It is one shared web every frame draws from, plus a private wing per frame; the big hexagonal KEYSTONES are build-defining.

MACHINE DESCENT does not give each frame its own skill tree. Instead there is one shared lattice — a single large web of nodes that every frame can path through — plus a private "wing" bolted onto each frame's core. In scripts/game.gd, the whole board lives in the SKILL_WEB constant (nodes), WEB_LINKS (edges), and WEB_CORES (which node is which frame's root). There are 115 nodes in total: 73 shared (including the 6 cores) and 42 wing nodes (6 wings × 7 nodes each).

Frames and trees

There are 6 frames, one per entry in WEB_CORES. Each has a free, pre-owned root node (cost 0) that anchors it to the lattice:

web_nodes(runner) returns the tree a single frame can see: it walks SKILL_WEB and keeps a node only if it has no only tag (shared lattice) or its only tag matches that frame. Every other frame's wing is omitted entirely — as the code comment puts it, "six trees that differ in shape read as six trees, not one tree with locks." A node carrying only is that frame's private wing (web_is_wing()), and a wing only ever upgrades the signature weapon that frame is born holding — its bonuses use the signature-scoped keys sdmg/scdr, never the whole arsenal.

The central hub and its gates

At the middle of the shared lattice sits a ring where all six frames converge. Four junctions (minor, cost 1) sit at the corners, four gates (notable, cost 3) sit between them, and the keystone ZERO-SUM CLAUSE sits dead centre, reachable only from all four gates. The ring links run junction → gate → junction all the way around (hb_nw → gate_n → hb_ne → gate_e → hb_se → gate_s → hb_sw → gate_w → hb_nw), and every frame's outer branch feeds into it (e.g. bw_bulk → hb_nw, hv_rigs → hb_ne, te_mono → hb_se, co_bus → hb_sw, sc_trigger → gate_w, ve_bus → gate_e, ks_mono → gate_n, ks_liquid → gate_s).

The HELL unlock node

HELL is not a fill percentage — it is a single clearance node on the web.

NodeNameClassCostEffect (hooks)
hell_keyBLACK ICE CLEARANCEnotable3dmg 0.06, armor 0.10, unlocks_hell: true

BLACK ICE CLEARANCE rings all four hub junctions (hell_key links to hb_nw, hb_ne, hb_se, hb_sw), so every frame reaches it exactly one step past its own hub. hell_unlocked() loops over WEB_CORES and returns true if any single frame owns hell_key — buying it on one frame opens HELL for the whole account, and difficulty_count() then exposes the top difficulty tier. It is a real node too, not just a gate: the dmg 0.06, armor 0.10 are meant to help you survive floor 1 on HELL.

Total cost and the (absent) cap

web_total(runner) sums the cost of every node a frame can reach, skipping the core_ roots. Because the shared lattice is a constant and every wing has the identical shape (3 minors + 3 notables + 1 keystone = 18 tokens), the total is the same for all six frames:

ComponentTokens
Shared lattice (buyable, excludes 6 cores)190
One frame's private wing18
web_total (per frame)208

There is no artificial cap: web_cap(runner) simply returns web_total(runner). A frame can fill every node it can reach; the only limiter is the tokens it has actually earned. Signature rank is now purely a HUD badge and no longer rations allocation, and HELL is gated by the hell_key node rather than by web completion.

Chaos "death spite" (scripts/enemy_manager.gd)

_chaos is resolved once per run in _refresh_difficulty() from DIFF_CHAOS, so on HELL _chaos = 2. Two behaviours key off it:

  • Lunge (_chaos >= 1, so HARD + HELL): a machine within dist < 96.0px of the frame closes 1.45× faster (mv *= 1.45), so kiting stops being a free answer.
  • Death spite (_chaos >= 2, HELL only, ~line 2813): when any machine dies *except* T_OVERLORD and T_SAPPER, and the enemy-shot pool has room (_shots.count < MAX_SHOTS(768) − 8), there is a 15% chance (randf() < 0.15) it fires a parting volley through _fan() toward the player — dir = (_player.position - pos[i]).normalized(), speed 190, bolt scale 0.8, colour = the machine's type colour, damage = EnemyShots.DMG(9.0) × 0.5 = 4.5 per bolt. Because it routes through _fan(), on HELL it is a 3-shot fan (DIFF_VOLLEY=3) at 0.17 rad spread, and the bolts inherit DIFF_SHOT_SPEED=1.20 (190 × 1.20 = 228 effective). Clearing a pack at point-blank still costs you something — at 15%, "punished, not forbidden".
